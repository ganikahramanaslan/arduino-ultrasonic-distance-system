# Arduino Ultrasonic Distance Measurement System

An ultrasonic distance measurement and warning system developed using Arduino Uno and HC-SR04.

## Hardware Components
- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- LEDs (Red, Yellow, Green)
- Buzzer
- 220 Ohm Resistors

## Technologies
- Embedded C++
- Arduino IDE
- Digital Input / Output
- Ultrasonic Sensing
- Serial Communication

## Features
- Real-time distance measurement
- LED-based distance indication
- Audio warning system
- Distance-based alert levels

## Learning Outcomes
- Understanding ultrasonic sensors
- Pulse measurement
- Digital signal processing basics
- Conditional control structures
- Embedded programming
